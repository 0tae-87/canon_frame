# 논문 구성안 (IPIU, 4–6쪽 가정)

## 제목 후보
- 가려진 물체의 파지를 위한 점군 완성: 관측 프레임 보정이 완성 자체보다 중요하다
- Completion is only as good as its frame: 단일 시점 부분 점군의 프레임 회귀로 완성 기반 파지 복원

## 초록 (핵심 문장)
단일 시점에서 한쪽이 가려진 물체는 관측 점군의 bounding box가 물체 프레임과 어긋나(중심 오차 ≈ 0.2 r) 완성
네트워크의 입력 정규화가 틀리고, 그 결과 완성 기반 파지가 부분 점군 파지보다 나빠진다(40 % 가림: 41 vs 47 %).
ShapeNet-55의 단일 시점 부분 점군으로 학습한 경량 프레임 회귀기(1.4 M, ≈1 ms)로 완성 전에 재정규화하면
파지 성공률이 부분 점군 대비 +5.4/+7.1/+9.1 pp(가림 0/25/40 %, 14 물체, 700 시행/셀, McNemar p < 0.003)로
회복되며 완전 시야에서 비용이 없다. 완성 네트워크와 파지 생성기는 변경하지 않는다.

## 1. 서론
- 완성 기반 파지 파이프라인(ICRA 선행 연구)의 전제: 부분 점군의 정규화 프레임 = 물체 프레임.
- 문제 제기: 가림 하에서는 이 전제가 깨지고 "완성이 해가 되는" 영역이 생긴다 (Fig. 2의 plain 곡선).
- 기여: (i) 원인 규명(yaw가 아니라 중심; Fig. 5), (ii) 센서 일치 학습 데이터로 만든 프레임 회귀기(Fig. 1, 7),
  (iii) 가림 정도에 따라 커지는 파지 이득과 시뮬 메시 벤치로 본 메커니즘(Fig. 2–4, 6), (iv) 닫힌 대안들(표).

## 2. 관련 연구 (짧게)
- 점군 완성(PoinTr 등)의 입력 정규화 관행; 정준 프레임 추정/등변 네트워크; 완성 기반 파지; 불확실성 기반 게이팅.

## 3. 문제 진단
- 3.1 yaw 민감도: CD +27 %, epistemic ×8.6(r 0.96), 오프라인 회복 가능하나 서버 경유 0 % (Fig. 5a).
- 3.2 중심 오차가 지배: bbox 중심 +75 %, 무게중심 +124 %, 스케일 무해; 형상 의존이라 학습 필요 (Fig. 5b, c).

## 4. 방법: 프레임 회귀기
- 입력/출력, 구조, 손실 (PROTOCOL §6). 핵심은 학습 부분 점군의 생성 방식: hidden-point-removal 단일 시점 +
  측면 가림 증강. 반공간 crop으로 학습한 v1이 실제 depth 뷰에서 중심을 더 틀리게 만든 사례(10 → 31 mm)로 동기 부여.
- 서버 통합: 기존 파이프라인의 wire 규약 유지, 추가 지연 ≈ 1 ms.

## 5. 실험
- 5.1 설정 (PROTOCOL §1–4): Isaac, Panda, GraspGen, YCB 16/14, 측면 가림 0/25/40 %, 50 시행/셀, McNemar.
- 5.2 주 결과 (Fig. 2, 표 1): 가림에 따라 커지는 v2의 이득; 전 시야 무손실.
- 5.3 물체별 (Fig. 3): 이득이 큰 물체(soup can, potted meat, foam brick, mug)와 중립 물체(상자류: 평면이라 프레임 무관).
- 5.4 재현 (Fig. 6): seed 1, 독립 추첨 두 번.
- 5.5 메커니즘 (Fig. 4): 벤치 CD 12.6 → 9.6 mm, 측면 중심 오차 25.9 → 17.8 mm; 실행된 완성의 CD 순서가 파지를 예측.
- 5.6 **전이 (Fig. 8, RESULTS §7)**: 같은 회귀기를 공식 SeedFormer에 재학습 없이 붙여도 CD −12.5 % / −28.6 %(40 % 가림, 133/150) —
  보정이 특정 완성 네트워크가 아니라 입력 프레임 문제를 고친다는 증거. 한계: 오프라인 형상 평가만.
- 5.7 대안 비교 (표 2, RESULTS §5): 불확실성 게이트, yaw 정준화, 선택기, 학습 트릭, 자체 불확실성 게이팅 — 모두 무효.
  메시지: **프레임이 맞고 나면 완성 정확도(−10 % CD)도 파지를 더 움직이지 않는다.**

## 6. 한계와 향후 연구
- 시뮬레이션 전용; 전 시야에서 v2 − plain −3.5 pp(n.s., 16 물체) / +1.1(14 물체); 클램프류(ShapeNet 미포함 형상) 실패;
  25 % 가림은 seed 0만. 향후: epistemic 방향으로의 재관측, 회귀기 형상 커버리지 확장, 실로봇 검증.
